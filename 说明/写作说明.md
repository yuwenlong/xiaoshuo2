### 失败处理流程

```
发现违规 → 立即停止 → 修正 → 重新验证 → 通过后方可继续
```

具体：

- **凡改写任何一句 → 重跑一键全套机检 `python ai-tasks/scripts/batchcheck.py 起章 止章`（BATCH_RC 须为 0），不得只跑与本次改动相关的那一项。**「按下葫芦浮起瓢」是改写的固有属性，**R20 已八次复现**：为消事后全知旁白→引进"那"字开头句；为避跨章重复→把纯动作改成情绪翻译；为修视角越界→写进破折号；新写对话→叙述语截断混搭×3。
- 发现序数词 → 立即删除或替换 → grep验证 → 通过
- 发现斩钉截铁断言 → 立即改为留有余地 → 人工复核 → 通过
- 发现结尾拔高 → 立即改为动作/场景/疑问句 → 人工复核 → 通过

**强制闸门（硬 gate）**：每批续写动笔前，必须先读该书反馈原文区块＋该书《人物小传》动作化辨识度锚，再逐章过§七「每章过签自检表」；反馈红线有一项不过，该章重写，不得进入下一批。控制卡批次约束须写明"已过签约红线自检"，否则视为未过签。

## 大纲节奏铁律（最高优先级）

以下规则具有绝对权威，任何情况下不可违背：

- **绝对依从**：后续续写必须严格按照《说明/全书大纲.md》的章节节奏推进剧情。
- **事件锁定**：严禁提前消耗、挪用或跳过任何大纲规划的核心事件（如告白、服战、见家长、求婚等）。
- **区间权威**：大纲的卷/章段划分是剧情节奏的唯一权威。某事件规定写在哪个区间，就必须落在哪个区间。
- **冲突处理**：若创作中出现与大纲冲突的新点子，**必须先请圣上定夺**是否修改大纲。获准后方可动笔；**严禁先写后改大纲迁就正文**。
- **控制卡核对**：每批章节动笔前，**控制卡**必须逐项对照大纲，核对本批应完成的剧情节点，确认无误后方可开始写作。
- **风格铁律**：全书执行"快节奏·强冲突"最高风格标准（见本文〇·一），每章必有可一句话概括的冲突核心+章末钩子六类轮换；与大纲节奏冲突时以本文〇·一为准。

## 〇、写作准则（最高优先级）

1.  **强制工具与提示词优化**：
    - **Skill 加载令（硬gate·每批动笔前必执行，缺一视为未过签）**：续写/审校必须使用 skills 能力进行小说创作，名单与必读文件锁定如下——
      1. **novel-control-station**：读 `SKILL.md`（控制体系，本书控制卡即其产物）；
      2. **human-writing**：读 `SKILL.md`＋`references/fiction.md`；初稿完成后再读 `references/revision.md`；
      3. **story-long-write**：读 `SKILL.md`，续写场景再读 `references/workflow-daily.md`；
      4. **story-deslop**（去AI味·交付前）与 **story-review**（审稿轮）按场景触发，触发即登记；story-review 三个检查脚本每批写作轮也跑（并入一键机检⑩），不以「没进审稿轮」为由跳过。
      **冲突仲裁**：skill 规则与本文冲突时以本文为准——human-writing「成稿正文严禁冒号、破折号」本书照收（见§四-11④停顿三禁；对白里人物原话的时刻数字不在此列）；story-long-write 的 Phase 工作流、作者记忆脚本与本书「控制卡＋执行协议」体系重叠处，以本书体系为准。
      **登记**：每批控制卡必须含「skill登记」行，格式：`skill登记：NCS已读 / HW已读fiction.md / SLW已读`（本批触发 deslop/review 者一并登记）；无登记行视为未过签，机检⑥查之。
    - **关键**：必须**精心设计提示词**，而非简单的"写第XX章"。应明确告知AI本章的**核心任务、目标读者、需避免的词汇、特定的风格要求**。
    - **前置锚定（去AI化核心）**：提示词首句必须给AI塞入一个**带情绪、有立场的角色身份**，而非让它以"客观旁白机器"的身份写作。**平台AI检测的第一靶心就是"没偏好、没情绪、永远端着架子审视一切"的理中客文风**（详见§五-4）。
    - **锚定人设四件套**：给AI的角色身份必须同时携带——**身份**（具体的人，不是"资深专家"）＋**环境**（此刻在哪、刚经历了什么）＋**情绪**（带着什么心情写）＋**一处失败/不完美**（他搞砸过什么、正在为什么别扭）。专家人设必然产出"周到而正确"的论文腔；带失败经验的活人，笔下才有卡壳、有反问、有忽然冒出来的旁枝——这些"不顺"正是检测系统识别真人的指纹。

2.  **严禁注水（含"正确的废话"）**：
    - 不得为了凑字数而注水，确保内容高密度、高质量。
    - **判定标准**：通读全文后逐句问"删掉这句，读者会损失什么？"答案是"没损失"就果断删除。
    - **框架先行**：动笔前先搭好本章框架——列出要写的场景、要推进的信息点、要埋的伏笔。框架的作用是**事前发现空洞**。

3.  **核心原则（反AI死穴·人本注入）**：
    - **拒绝冷冰冰的概率文字**：文字必须带有"体温"和"痛感"，描写要有生理性的细节支撑。
    - **拒绝流水线套路**：即使是甜宠爽文，也要写出独属于两个主角的"黏稠感"和"烟火气"。
    - **拒绝直白宣泄**：学会"留白"，用环境、动作和微表情来映射情绪。
    - **注入个性化痕迹**：加入作者对生活细节的观察、独特的比喻、非线性的联想。
    - **语气留有余地**：AI的致命特征是**语气过于肯定**。人类写作天然带有犹豫、不确定和自我怀疑。**铁律**：叙述语气必须有松有紧，禁用"必然""绝对""毫无疑问""显而易见"等斩钉截铁的断言。
    - **不编造经验与事实**：涉及具体数据、机构、人名、年份的内容必须有来源依据；不确定的部分宁可不写。
    - **禁用序数词连接**：严禁使用"第一……第二……第三……"、"首先……其次……最后……"等序数词堆砌段落。改用情节推进、因果关系、时间流动来自然串联。
    - **删除结尾拔高式总结**：严禁用"综上所述"、"由此可见"、"我们要相信"等拔高式口号收尾。好的结尾是一个具体的动作、一个未完成的场景、一个悬而未决的疑问。

4.  **网络社区对话抗AI检测（核心命脉·本书无游戏世界观，对应物如下）**：
    - 博客评论区、公众号留言、QQ/雁信群聊、饭局群聊等纯对话场景是AI检测的"高危区"。**必须**在连续群聊对话中穿插私聊或主角内心OS，**每连续5行群聊对话内必须有打断**。
    - **必须**将群聊对话的通用词汇替换为该年代该圈子的专属黑话（以大纲「技术口径」年代栈与人物口头禅为准；年代网络梗宁缺毋滥，过期梗视同失真），增加专有名词密度以降低AIGC值。

## 〇·一、快节奏·强冲突总纲（投稿反馈修订·最高执行标准）

> 投稿反馈：主流网文平台签约门槛为**快节奏、强冲突、开篇爆炸**。本章为全书最高风格指令，与下文各章规范冲突时，以本章为准。

### 1. 开篇爆炸标准（黄金三章定生死）

- **第1章前300字**必须抛出核心冲突或强悬念事件，禁止任何形式的慢热铺垫、世界观介绍、背景叙述。
- **第1章**完成：主角辨识度场景 + 第一个冲突 + 章末强钩子。任务是把人钉在椅子上。
- **第2章**任务（让人坐住）：给出第一个小爽点/反转，回答"这人凭什么赢"；反派开始施压，但主角已亮出破局的苗头。
- **第3章**任务（逼他点下一章）：主角对阻碍给出解法，读者拿到一次小回报，同时埋下更大的雷。
- **前三章内**完成：核心关系钩子确立 + 第一个小高潮。
- **核心卖点亮相时限**：核心设定/身份钩子（金手指、书名承诺的前提）前三章内必须亮相；**亮相≠兑现**——身份要早亮，书名承诺的核心爽点仍按「〇·一-8 延迟兑现」压到节点引爆。
- **平台差异原则**：免费平台求快、付费平台求稳；本书执行最严档（第1章前300字抛冲突），不分平台降级。
- **前十章内**必须出现第一个"爽点"。
- **开篇字数标准层级**：①第一句话必须有钩子 → ②后续章节前100字必须出现动作/冲突/异常 → ③第1章前300字必须抛出核心冲突。
- **冲突对话开场优先**：首句优先落**冲突对话**——对话开场自带人声与立场，是3秒入戏的最短路径；正文前50字内宜直接抛出冲突对话（争吵、质问、爆炸性通知均可），交代背景一律后置。

### 2. 每章强冲突（全书通则·无冲突章禁令）

- 每一章都必须有一个**真正的冲突点/压力点**——对抗、阻碍、反转、抉择、外部事件、立场碰撞，至少其一。
- 每章**必须再有一个可一句话概括的冲突核心**。
- 即使是日常甜章，也要有"目标—阻碍—反转"的冲突结构，**阻碍必须真实存在并有压力**。
- **三问自检**：本章冲突能否一句话说清？冲突有没有明确的对抗方/阻力源？读者会不会替主角捏把汗或拍案？三问有一答否，即重写。

### 3. 信息密度三层论（反"伪节奏"·全书通则）

**信息三层递进**（由浅入深，每章至少覆盖两层）：

| 层级     | 说明                                             |
| -------- | ------------------------------------------------ |
| 事件信息 | 最表层——发生了什么、拿到了什么、去了哪           |
| 情感信息 | 藏在事件背后——读者心里觉得憋屈、释放还是感动     |
| 关系信息 | 最致命——角色间的信任/裂痕/试探发生了什么微妙变化 |

- **每写几千字必须塞一个读者没见过的"盲盒"**（意想不到的设定/反转/关系变化）。
- 如果一章只有事件信息（流水账式报幕），没有情感或关系层的推进，即"伪节奏"，重写。

### 4. 章末钩子强制（每章必落）

每章结尾必须落一个钩子，六类轮换使用，禁止连续三章用同一类：

| 类型     | 说明          | 示例（通用）                               |
| -------- | ------------- | ------------------------------------------ |
| 悬念未决 | 问题抛出未答  | "他发来一行字，她盯着看了十秒，没敢点开。" |
| 突发事件 | 新变量闯入    | 手机响了，来电显示是她最怕看到的名字。     |
| 情感转折 | 关系突然位移  | "以后别叫我老名字了。"                     |
| 秘密将揭 | 真相露出一角  | 备忘录里那一条，是空的。                   |
| 冲突升级 | 矛盾加码      | 公共频道刷出那句话时，全场静了。           |
| 反差收尾 | 预期违背/幽默 | 精心准备的现场，被最不该出现的人撞个正着。 |

- 钩子必须"具体、有画面、与下一章开头呼应"，禁止"他不知道的是……"式空泛预告连用。
- **章首承接时限**：上章章末钩子须在本章前300字内被接住（回应、加码或被新变量打断皆可），不得先写一段别的事、插一段回叙再回头补；只接到「怎么样了」，不替后章作答（R73）。接钩方式随开篇形状一并登卡，同一接法连用≤2章。
- **钩子对话优先**：章末钩子优先用**一句具备悬念或反转力量的对话**承载（"悬念未决/情感转折/秘密将揭"三类天然适配对话式收尾）；仍受六类轮换、同画面不复用约束，不得为凑对话钩而连用。

### 5. 四件套：爽点·泪点·虐点·笑点（全书节奏骨架）

- **爽点（三档）**：
  - ①**章内小回报**：每章必有，且有见证者（〇·一-12／13）。
  - ②**当众兑现**：按〇·一-15 五步循环跑完一轮；相邻两次间隔≤3章（中间至多隔两章），间隔章里须有一次底牌前兆或有见证的章内小回报垫着。**大纲已锁章段**若超限，不改大纲事件，在间隔章内用前兆＋小回报垫，并在控制卡「爽点循环」登记超限理由；新排纲一律按≤3章排。「≤3章」是上限不是节拍，一批内落点须参差。
  - ③**大爽点**：单元末当众兑现＋资产或身份跃迁，按大纲单元表执行，每卷≥2。
  - 控制卡逐章规格「兑现」格标档位〔小〕〔众〕〔大〕，「爽点循环」节写明「上一次当众兑现：第N章」。
- **泪点**：每卷至少一个大泪点。
- **虐点**：每卷至少一个大虐点，虐后必须有回应（甜或爽）回收情绪。
- **笑点**：分散各章，虐章后一章宜有笑点缓冲。
- **配比红线**：连续甜≤5章必须插入一次张力；连续虐≤3章必须给出口；全书甜:虐≈7:3。

### 6. 节奏起落（全书情绪曲线）

- 每卷节奏为"起—扬—挫—爆"：卷首快速立冲突，卷中推进，卷末大高潮+大钩子。
- 卷与卷之间不许"软着陆"：本卷最后一章的钩子直接引爆下一卷开篇。
- 平台推荐节点（3万/8万/15万字前后）必须落在爽点或高潮章上。

### 7. 强冲突的执行边界

- 强冲突≠狗血：冲突须符合人设与逻辑。
- 冲突优先级：外部事件 > 立场对立 > 信息差误会。
- 甜宠/轻松底色不变：强冲突是"节奏引擎"，不是把甜文改成虐文。

### 8. 签约榜公式（扫榜对标·硬指标）

- **首句即炸**：执行「〇·一-10 开篇六条铁律」①②条。
- **反派速恨**：主要对抗方有名有姓、有自污细节，且当卷付出可视化代价。
- **人设动作化**：性格标签每章至多出现一次，此后只许用新的失误动作/行为细节呈现。
- **钩子去同质**：同类情感钩全书连用≤1次，画面不得复用。
- **延迟兑现**：书名、简介承诺的核心爽点用小道具/引信压到节点引爆。

### 10. 开篇六条铁律（3秒入戏·发布前必审）

| 条目        | 铁律                     | 执行标准                                                 |
| ----------- | ------------------------ | -------------------------------------------------------- |
| ①钩子扎进去 | 第一句话制造具体问题     | 钩子必须落在**具体事件**上，不是交代背景。               |
| ②麻烦追上来 | 三百字内三要素露面       | **主角是谁**、**眼前问题是什么**、**不处理会失去什么**。 |
| ③设定压人   | 设定必须影响人物选择     | 删掉这段人物选择会不会变化？不会就不该出现在这里。       |
| ④情绪往上拧 | 压力逐步升级             | 压力出现→人物选择→结果偏离预期→新问题被迫出现。          |
| ⑤让读者疼   | 用动作细节代替情绪形容词 | 一个能改变动作节奏的细节，比四个情绪形容词更有力量。     |
| ⑥关一扇门   | 章末钩子由本章结果逼出   | 好的章末钩子是**本章选择造成的后果**。                   |

| 普通写法                                           | 更有效的写法                                                           |
| -------------------------------------------------- | ---------------------------------------------------------------------- |
| 大业七年，天下承平，西域诸国风云变幻。             | 城门落锁时，沈聿怀里多了一封不该出现的死人信。                         |
| 青崖山传承千年，门中分为七院，观微院专司……         | 沈聿没有拔剑。青崖山弟子不得在凡城先伤官兵——除非他愿意把使团也拖下水。 |
| 他呼吸急促，双眼通红，浑身颤抖，手指死死掐进掌心。 | 门外第三次响起脚步时，他才发现自己一直捏着那张纸。纸角已经被汗浸透。   |

### 11. 章内情绪流：三压一震（情绪曲线铁律）

- 每章情绪遵循**"前三番压、最后一震"**的递进结构：前三次冲突不断积蓄压力（一次比一次逼近主角底线），最后一次彻底引爆释放。
- 拒绝平铺直叙或一路萎靡的情绪曲线；甜章同样适用——压力可以是"想说不敢说""想信不敢信"这类内压。
- 自检：本章的三次加压点分别是什么？最后一震落在哪一段？答不出即重写。

### 12. 榜文沉淀·开篇与章内实操技法

> 以下为可复用技法，与上文各章规范配套执行；冲突时以本节上文条款为准。

**开篇下钩三法（任选其一，首段必须反常）**：

- **首句即反常**：第一句话抛出与日常逻辑相悖的画面或对话（牛顿在群里问作业、主角敲开仇家的门）。
- **他人之嘴**：主角未登场，先用旁观者闲话/群聊交代他的标签与死局；敌人之嘴与亲人之嘴各唱一台戏，一章内信息、冲突、感情伏笔三合一。
- **镜头急转**：先抛高信息密度的异质场景（告警刷屏、讨债现场），一句话拉回现实坐标（时间＋地点）。

**数字刺痛条款**：涉及钱、赔偿、房贷、投递次数、倒计时等现实压力，必须写具体数字（欠858.52元式精确到小数点），禁止"很多钱""欠了不少"式概括。

**每章一兑现一钩子**：章内必须兑现一个小回报（专业操作漂亮完成、被一句台词认可、关系位移），章末留一个更大的预期。压抑题材（裁员、意难平）压抑更深，必须加密小兑现密度补偿读者，否则弃书。

**配角一句立人**：配角首次出场只给"一个动作＋一句台词"，禁止背景介绍段；履历融在戏里交代。

**装孙子开局**：主角可先忍辱（赔笑、背锅、被晾），再凭真本事反转，爽感来自反差；反转必须有前文铺垫的凭据，禁止天降解围。

**对照组露馅法**：主角过难关（面试/述职/评审）之前，先写一个同处境者出丑落败，主角的紧张与含金量才有实感。

**危机升级链**：每章解决一个旧危机，同时引爆一个更大的危机；冲突优先级仍按〇·一-7（外部事件＞立场对立＞信息差误会）。

**专业即爽点**：把真实的排障、评审、重构、救火过程写细写香（如美食文写拉面炫技），专业细节承担情节转折功能，不是科普负担；仍受§三-2术语通俗化约束，且技术准确性按 `ai-tasks/lessons.md` 铁律执行。

**感情线只埋不碰**：感情暗线在开篇阶段只给碎片信息（一个名字、一张名片、一个空文件夹），不给正脸、不展开、不点破。

**情绪落在当下**：事发当下的内心戏要凉、要硬（动作/账本式短句）；"大概是…吧"式复盘调侃只给有时间距离的章节，压力现场禁用。

**隐喻不点破**：书名/题眼/主题隐喻只写可感短句，删"这道理搁在……也说得通"式画重点句；寓意交读者自架，作者不代答。

**提示配重**：给主角的提示/线索若不能立刻兑现，压到压力峰值处再放（"最后一根稻草"位）；提示早放而长期无效，读者必质疑；提示不得替主角解题，答案仍须主角自己挣出。

**沉默者往事被引出**：话少/命令式人设的角色不得主动讲带教导意义的往事，须由对方顶嘴或追问逼出；对话内禁止括号式术语解释（破人设），通俗化用口语加重词与后果呈现（§三-2配套执行）。

**不能学清单（红线）**：系统面板/任务提示/属性数值即时反馈、异能实物化（红包/抽奖/实物具现）、强刺激暴力尺度——本书金手指恒定为「重生记忆＋技术＋判断力」，受「一-6 先知兑现纪律」三律约束（模糊/折旧/守口）。爽点只许来自"信息差当众兑现＋技术降维打脸＋资产数字跃迁"，且每笔兑现必须配代价与反对声（一-6），禁无成本摘桃、禁记忆增值。

### 13. 榜文实证增补条款（榜单范文拆解沉淀·硬执行）

> 依据：三江榜5本＋新人签约新书榜5本＋新人作者新书榜5本逐本拆解（结论台账见 `ai-tasks/lessons.md`）。以下条款与上文冲突时，以本节为最新增补。

- **死局必须落在主角本人头上**：开篇危机是主角自己的危机（债务/死线/背锅/裁到主角本人），能量化必量化（金额/倒计时/名额，沿用数字刺痛条款）。主角旁观别人的危机只可作引线，不得作主冲突——压迫感隔一层，榜单文无一例外。
- **核心竞争力前三章内当场管用一次**：主角的立身之本（技术/手艺/阅历）必须当众解决一个具体麻烦。"身怀绝技但一直没机会展示"拖过三章即判慢热。
- **爽点必须有观众（外放兑现铁律）**：每章的小兑现必须配见证者反应——对手吃瘪、权威点头、同事改观、客户当众验收，至少其一。禁止"深夜独自完成、无人知晓"式内敛兑现单独成立；内敛场景可保留，但章内或紧挨的下一章必须补一个外放的承认时刻。
- **对照组先贬后立**：主角过难关之前，先给同处境者一句轻慢/质疑/失败（成本一两行），反转才有实感；该轻慢者在兑现时刻必须给一个反应镜头，形成闭环。
- **男频开篇感情线实证**：15本中11本前三章零女主——前三章无女主不是缺陷，是常态；「感情线只埋不碰」条款维持不变。凡简介、开篇以情感对话/情感悬念打头阵者，视为女频化红线，直接重写（内投退稿实证：简介言情化致编辑误判定位）。
- **简介频道对板条款**：简介先卖主线最硬的画面，情感暗线只留末尾一句钩；简介承诺什么，前三章必须交付什么，定位错位视同重大事故。

### 14. 外部审稿沉淀条款（外部审稿沉淀·硬执行）

- **禁单章纯生活戏**：每章必须推进至少一条剧情线（新事件/新矛盾/新钩子）；生活质感揉进事件章，不独立成章。
- **同构场景间隔红线**：相同骨架的"出问题→解决"模式两次出现间隔≥5章，再现时必须换呈现动作。
- **主角被动接招上限**：连续被动接招≤10章；超限前必须落一次主角自己决定、超出分内的主动出击。
- **口癖场景去复读**：同一配角同一口癖场景≥3次即报警；此后每次出场必须带增量（新信息/新动作/一句能记住的台词），否则压缩戏份。
- **重要配角隐身检测**：压力源型配角不得整章蒸发；真不出场须留存在感拍（一句话或一个动作，须改变压力或预期；纯点名、他人顺口提一句不算），控制卡登记原因；人物与线的冷热按§四-13 线索热度表管。
- **身份级认知检验**：台词里的"不知道/没听过"须过人物身份检验；写"不会操作"可以，写"不知道本行业基础概念"失真。
- **伏笔滞后释放条款**：预警句与引爆不得同章相邻——"刚说一句'别乱动'，同章结尾就出事"的因果贴脸，读者只会"哦，果然"。预警句须单独成立（当时读不出指向、读者快忘了），引爆改由后章突发承载，回收时让读者与主角同一拍反应过来前文的指向。
- **台词分量匹配条款**：情感高点的台词分量须与人物资历、关系进度匹配。刚闯祸的新人/受惠者禁江湖式重誓（"我跟你混""赴汤蹈火"式）——分量过大即失真（"这小子怎么这么会说话"）；以动作（捧物不撒手、抹脸跟上）或轻台词（"我会学的"级）收尾，情感靠画面承载，不靠台词强调。

### 15. 当众兑现五步循环（单元与章群通用）

> 依据：外部爽文拆解「压上来→底牌前兆→当众兑现→围观反应→奖励落袋新麻烦上桌」＋story-long-write 爽点三要素，按本书金手指边界改写。爽感的来源是信息差：读者知道主角手里有什么，对手不知道。

- ①**压上来**：对手带着具体的恶意或现实压力出场（抢功、甩锅、压价、卡流程、钱的缺口），有名有姓有手段有数字，禁「被欺负了」式概括。
- ②**底牌前兆**：兑现前至少隔一章，或在同章前半（不得紧贴兑现段），让读者单独看见主角手里的牌：他亲手埋下的一笔记录、他记得的一个方向（只写区间，模糊律）、他做过的一次验证、他算过的一笔账。**只在主角视角内露，对在场人守口**；禁系统提示、物件发烫类前兆（不能学清单）。
- ③**当众兑现**：人多、有赌注、当面。扳机握在主角手里，兑现用的必须是②埋下的东西（grep 得到出处），外人只附和（R51）；禁天降解围与临场新设定。
- ④**围观反应**：见〇·一-13 与〇·一-16。
- ⑤**奖励落袋，新麻烦上桌**：实利（钱、职级、名分、资源、人）写成看得见的一笔，数字过资产台账；**落袋写在新麻烦之前**；新麻烦只取大纲已排的下一节点，由更大的对手「看见他」引出，循环规模升一级。
- **写崩三禁**：只压不爽（超出〇·一-5 间隔）；只爽不压（底牌始终比麻烦小半号，与折旧律同向）；靠巧合兑现。
- **控制卡「爽点循环」节**：动笔前填五格（压／前兆位置／兑现场／见证人／落袋与新麻烦），逐章规格「循环步」栏写本章走到第几步；答不出「这一章循环走到哪一步」的章，只是字数，不是故事。

### 16. 兑现场的在场者账

- ①**标价先于兑现**：这事多难、多值钱，由在场有立场的人在兑现前说出来（内行估价、老规矩被打破、平常要花多少代价），叙述者不替他们断言；尺子至少两把，且先于被度量的事出场。
- ②**反应分立场**：赢面方改口，输面方推责，拉不下脸的转攻别处；遮住名字认不出是谁的反应即重写；禁全体折服。
- ③**说话权分级**：一场戏台词至多给三到四人，地位越高动作越少越静，同立场者合并。
- ④**对象要有分量**：路人震惊不算兑现；打脸对象的层级决定爽感层级。
- ⑤**中间态与最重一句**：详写场景给中间态（先怎样、跟着怎样、最后成了什么），不只给起点终点；全章最重的那一拍用最短的一段承接；详写处禁「一连七八下／半晌／众人纷纷／三言两语说明了缘由」式量词概括，交锋台词逐轮写出。

### 17. 结算权与契约四问

- 单元核心收益（功劳、名分、钱、职级、资源）最终须结算回主角，或回到他事先授权的人；被拿走只能作「压上来」，且须在本单元内以看得见的交换讨回。配角、上级、机构、巧合不得无交换地替主角做关键选择或收割高光。
- **批末契约四问**（写入控制卡「机检与自检结果」）：是不是靠主角自己的选择挣到的？高光有没有被无交换拿走？有没有提前动用终局底牌、把某条线顶到天花板？旧期待付了利息没有？

## 一、硬性规定（不可违反）

1.  **真实名分层（唯一权威以《全书大纲》「名称使用分层表」为准）**：真实公司名/产品名**允许中性提及**（淘宝、微信、寒武纪、996等公开史实陈述）；**禁止**对真实主体的贬损映射（"xx公司垃圾"式指向性贬损）、**禁止**真实人名及其言行、**禁止**未公开内幕；承载负面剧情的机构一律虚构名；真实地名与校名仍禁（统一用京城/深城等虚构名）。
2.  **字数要求**：每章不少于2000字，建议控制在2000-3000字之间。特殊情况最多不超过3500字。
    - **统计口径（永久生效）**：字数一律按**作家助手显示口径**统计——**中文字符与中文标点逐字计，连续的数字/字母/半角标点串整串只算1字**，与起点作家助手显示值一致，所写所验即读者所见。机检估算与作家助手实测误差±2字，凡压线目标（如补字/卡2000）一律预留30字以上余量。
    - **批次口径**：续写**每五章一批写、每五章一批验**。
    - **自然波动铁律**：同一批次章节字数**禁止均匀分布**。**每个五章子批的字数极差必须≥500字**。
3.  **平台违规内容红线**：严禁恶意丑化公务人员形象、严重违背伦理与主流价值观、无底线制造和煽动性别对立等。
4.  **版权规范**：不得抄袭、融梗，世界观设定原创。
5.  **跨章数据一致性（硬性·全书铁律）**：
    - **数值口径统一**：首次亮出时即登记口径，后续章节一律沿用登记值。
    - **名单锁定**：评审/答辩/裁员/投资/被投等名单类剧情，阵容与顺序写进控制卡为强制项。
    - **跨章时间链**：含"第N天/第N次/隔了N天"类计数时，落笔前先列逐日日历反推。
    - **同一物件来源唯一**：第二次写到同一物件，先grep前章出处。
6.  **先知兑现纪律（重生文专属·不可违反）**：
    - **金手指三律**：①**模糊律**——主角记得趋势与量级，记不住精确日期与价格，正文兑现一律写区间；②**折旧律**——蝴蝶效应使记忆随剧情加速作废，**每卷至少落一次「记忆失效/记错」惊吓章**（落点见大纲各卷注记），2022年后只剩方向感；③**守口律**——主角永不向人完整解释信息来源（F5悬疑线），"逻辑链"是他的全部说辞，**笔记本内页全文永不展示、丢失/被偷看桥段禁写**。
    - **投资必有摩擦**：每笔投资必须配齐「等待期＋反对声＋代价」三件套中至少两件；禁买买买流水账，无冲突不成章。
    - **数字精确可核验**：投资账目精确到个位数并与大纲「资产台账」对账（每批收尾核对）；落笔前必过大纲「时代锚点表」，拿不准写区间不写点值；**禁写现实可操作的荐盘口吻**（防误导防杠）。
    - **金手指禁升级**：记忆只能折旧不能增值；"他突然发现还能预知更多"式桥段出现即重写。

## 三、世界观描写规范（现实职场版·本书无游戏世界观）

1.  **设定权威**：机构名、技术栈、时代锚点、资产台账等**一律以《全书大纲》「世界观·现实职场设定」节为唯一事实源**。
2.  **技术/商战场景描写（适配短篇幅）**：
    - **重要场景详写（300-500字）**：聚焦关键操作（修BUG的翻手册定位、评审会的当众打脸、逃顶夜的分批挂单），给"可感知的细节变化"（修复前后对比数字、见证者反应）。
    - **日常工序略写（50-100字）**：快速带过，或作为人物聊天的背景板。
    - **术语通俗化（强制）**：出现专业术语时，必须在上下文中用通俗语言解释其含义或作用。**禁止裸抛术语**（对标写法：XAMPP/jQuery Mobile式"内行看门道外行看热闹"）。
    - **技术表述内行检验（红线）**：语言/工具/生态的难度、门槛、优劣判断不许外行臆断（反面实例：PHP 比 C++ 平易，"C++的人看PHP像天书"即外行错误）；拿不准时写人（谁不会、谁敢不敢、谁没摸过这套环境），不写技术高低。**技术硬核是本书立身卖点，技术失真视同设定事故。**
    - **新术语限量**：新术语每章首次出现≤3个，一句之内不并列两个读者没见过的术语；首次出现先给它在场内的作用或后果（谁因它卡住、它让什么快了或坏了），名字后补；通俗化靠口语加重与后果，不靠括号释义（一键机检⑪按英文术语累积计数 WARN）。
    - **技术坑核触发（R102）**：拿当年真有过的技术坑、报错、平台机制写情节前，核三件事：当年的版本／参数能不能触发；报错页面当年叫什么；平台当年有没有这个机制。查不实就写人物的防备，不写平台的规定。
3.  **网络社区对话呈现方式（对抗AI检测专项）**：
    - 同本文〇-4：**必须**在群聊/评论区对话中**穿插**私聊或主角内心OS，**每连续5行对话内必须有打断**。
4.  **专属术语的自然嵌入**：
    - 将通用词汇替换为该年代行业的**具体行话/工具名/平台名**（以大纲「技术口径」年代栈为准；2011-2012禁出现Docker/微服务/中台等后世词汇），增加专有名词密度。
5.  **行情/数字描写比例**：单章内纯行情、盘面、资产数字段落占比≤20%，且必须挂靠人物动作与冲突（谁反对、等什么、怕什么）；禁行情流水账独立成段。
6.  **数字二次锚定**：资产、价格、薪资数字首次亮出时，同一段内折算成读者已付过代价认识的旧价值（他一个月工资、上一章的房租、兜里那几块钱），不隔章补；口径过资产台账与时代锚点表，不写荐盘口吻。

## 四、章节结构规范

1.  **章节标题**：口语化短句，长度自然不强求。
2.  **开头**：执行「〇·一-1 开篇爆炸标准」。**单章开头前100字内必须出现动作、冲突或异常信息**，禁止以天气、闹钟、起床流程开头。
    - **禁梦境/醒来铺垫型开头**：严禁"做了个梦……醒来全归零"式假剧情铺垫，直接入事，不铺垫"为什么"。
    - **禁配角视角开篇**：严禁从路人、反派或动物视角切入开篇；主角必须在300字内登场并行动。
3.  **结尾（拒绝拔高式总结·强制留白）**：每章结尾必落一个钩子（六类轮换），禁止平淡处断章。
    - **严禁结尾拔高**：禁止用"我们要相信"、"未来是无限的"等口号式总结收尾。
    - **正确做法**：用一个具体的动作、场景或疑问句结束。**留出未说完的部分，让读者自己去想。**
4.  **节奏把控**：执行「〇·一-4 四件套配比」；每章必有「〇·一-2 张力单元」，禁止无事件章。
5.  **篇幅节点控制**：分卷结尾应设置在平台关键推荐验证节点前后（如3万字、8万字、15万字等）。
6.  **结构去"八股文"化**：
    - **拒绝固定的"总分总"模式**：章节结构应服务于情节自然流动。
    - **过于工整本身即AI特征**：人工写作天然带有不规则性，刻意保留这种"参差"是对抗AI检测的有效手段。
7.  **对话行格式（全书统一·每批交付前必验）**：
    - 群聊、评论区等网络社区对话行**行与行之间必须有空行分隔**。
    - 叙述段落与对话行之间也须有空行分隔。
    - **交付校验**：每批章交付前须格式校验。
8.  **跨卷续写规范**：
    - **文件存放**：跨卷首章必须存入新卷目录。
    - **叙事衔接**：上卷末章的钩子必须在下卷首章承接。
    - **人物小传/线索表同步更新（强制·每批章完成后必做）**：新出场人物补小传条目；已有小传人物补新事件/台词/情感节点。
9.  **多章事件链跨章一致性（现实职场版）**：
    - **行情时间计量**：行情/股价/币价场景的时间词按交易日与月份计，与大纲「时代锚点表」对齐，禁用无出处的精确时点。
    - **数据驱动叙事**：资产/估值/用户量等数据口径须与大纲「资产台账」/控制卡一致。
    - **跨章事件链先画全链再动笔**：多章共用的大事件（裁撤日、股灾清仓、打新、IPO），动笔前先排出完整日期链与章位链。
    - **名单写进控制卡为强制项**（同一-5）。
10. **伏笔闭环机制（每章强制注明）**：
    - 每章交付时，在**控制卡**（或章末工作区，**不随正文发布**）附【伏笔处理】：
      - **回收**：收回前章伏笔「具体内容」，收回方式「写明如何触发、揭示」；
      - **新埋**：本章新埋伏笔「具体内容」，埋设位置「章节/段落」，关键细节「写明线索或异常点」。
    - 伏笔必须落在视角人物可感知的细节异常上（§五-8信息生长禁令），禁止凭空做局；台账同步记入该书大纲伏笔数据源。

11. **标点规范（全书统一·每批交付前机检零残留）**：
    - **引号**：对话、逐字引语、屏幕纸面消息原文、首次出现的专名或代号一律用全角弯引号“”（普通名词与作者临时概括的概念不加引号强调），正文严禁出现 ASCII 直引号 `"`；英文/代码片段作引语内容时外层仍用弯引号（如“jine”）。
    - **句中叙述语**：同一人的话被叙述语截断续说（“……，”某说，“……”），截断处用逗号不用句号；问号叹号保留；叙述语收句号另起新句时引号内句号不动。引语作句子成分（回了个“好”。）标点在引号外，属正确，不得误改。
    - **机检**：①grep 直引号 `"` 零残留；②grep `。”[^。”]{1,25}?，“` 零残留；③弯引号开闭计数相等。
    - **④停顿三禁（硬项）**：正文（叙述与对白）禁破折号（——／—／–／--）、禁省略号（……／...）；停顿、吞话、打断、说一半，一律由动作、句中叙述语截断或句号问号承担（如「他说七月里那条短信，他回的那个，话没说完，她接过去了」）。**叙述层零冒号**：屏幕、纸面、短信上的字写成「写的是“……”」或叙述带出，不用「：」引出；对白里人物原话的时刻数字不在此列。1-86 章存量叙述冒号不回修，87 章起零容忍（fullcheck 硬项）。

12. **重点位置精读（交付前硬动作）**：开头500字、章末200字、兑现与情感节点三处，逐句重写过一遍，不只读——开头查是否300字内接住上章钩、主角300字内有无行动、首句是否落在具体事件上；章末查钩子是否由本章结果逼出、钩前500字旁白有无预支钩子关键词（R54）、末句是否为动作／对白／画面／未决疑问；节点查最重一句是否最短、五感点、标价人。三处之内比喻、口癖、群体静默、轻补语零容忍（一键机检⑪对头尾两处 WARN）。控制卡登记「精读三处：改X句」。

13. **线索热度（NCS 遗忘元素控制）**：控制卡设「线索热度」表，核心人物、主副线、在途伏笔逐项标热／温／冷／封存，并记最近一次**有效触碰**（推进、施压提醒、关系改变、后果落地、写明理由的休眠）的章号；纯点名、客串、空回扣不算触碰。阈值：核心人物3-5章、主要副线4-6章、伏笔错过两次合理回收机会即转冷；转冷的下一批须选一种处置（推进／侧面提醒并改变预期／压力转移／写明休眠理由／封存），禁硬塞客串（一键机检⑪按人名最后出场章 WARN）。

## 五、文风规范（反AI死穴·情感物理化专项）

1.  **整体基调**：快节奏、强冲突，爽点泪点虐点笑点四件套齐备。**核心在于"真实感"与"个性化质感"**。
2.  **叙述视角**：第三人称，多主角视角均可。
3.  **对话比例**：对话段落占全文 40%-50%（**常规章档**，独处章与双人静场章另有区间，见下「章型区间」；**口径：按段落数计**——含对话的段落÷全文总段落数；引号内纯字符占比不作验收依据，仅供风格参考），**严禁**出现大段无对话的纯叙述或纯内心独白。**叙事加厚条款**：对话占比**上限50%**，对话之间必须以2-4句叙事段加厚感官/环境/动作细节。
    - **对话承载剧情**：核心剧情以对话推进，叙述只做加厚与转场，不抢戏。
    - **网感幽默条款**：笑点以对话承载，可自然植入网络流行梗制造笑点；**禁止用旁白或叙述硬挠笑点**。梗须贴人设、贴语境、不过期，一章至多1-2处，堆烂梗视同注水。
    - **口径注**：网传"对话占比70%+"**不适用于本书**——本书执行40%-50%＋叙事加厚，防纯对话流水账，与§三-5世界观占比红线配套。一律按段落占比验收。
    - **章型区间**：一刀切的40%-50%对两类章型夹得过紧（实证：ch148=39%／ch149=32%破下限、ch150=52%超上限，均系章型所致而非执行不到位），故按章型分三档验收——

      | 章型 | 判据（落卡时定，交付时按卡验） | 区间 |
      | ---- | ------------------------------ | ---- |
      | **独处章** | 全章无固定对手戏，主角独自行动（改简历/写博客/收拾东西/独自算账），对话只来自电话、IM、留言等远程介质 | **下限25%**，上限不设（超50%即非独处章，改按常规档） |
      | **双人静场章** | 全章基本只有两个人，且一方是限字人设（如秦深单句≤10字）或场景本身是静场（钓鱼/谈话/守夜） | **上限60%**，下限40% |
      | **常规章** | 上述两类以外全部 | **40%-50%** |

    - **章型判据铁律**：章型**必须在控制卡逐章规格里预先登记**，禁止交付时按实测值反推章型来迁就数字（那是"让规则去将就稿子"，与"让稿子去将就没校准的数"同罪）。一章只能挂一档；两档都像的按常规档。
    - **三档共同底线（不因章型放松）**：①对话之间仍须2-4句叙事加厚；②仍禁纯对话流水账与大段纯独白；③连续对话段无叙事打断、同一说话人连说两段无标识，仍为实质违规，与占比数字无关（lessons）；④**交锋场景豁免**：双人当面交锋（请缨、对质、谈判、验收问答），每句都带说话人或动作标识时，连续对话段以≤6段为限，不强求段间2-4句叙事加厚——交锋戏硬插叙事会泄掉节奏。
    - **对白四条**：①两个人都知道的事，不许为读者再说一遍，旧信息挂在分歧、赌注、面子上说出来；②重要对白每轮至少做两件事（推进、露人、改关系、藏话、侧漏），只交代背景的一轮压缩或改叙述带过；③全章对白语气词（吧、呢、啊、嘛、呗、哎、嗯、哦、呀、啦）不得为零，按人物身份分配，限字人设独占的章理由入卡；④对白占比不达标时先查章型登记，再加叙事厚度，禁为凑占比硬扩台词、禁把心理改成台词。
4.  **反AI句式禁令（核心风控）**：
    - **禁翻案腔（按动作判，不按字面）**：先立一个读者并没有的误解、再推翻它给下文抬价的句子，一律拆回正面判断，把依据放在旁边。已知外衣举例（清单不是边界）：字面（不是A而是B／并非A而是B／不在于A而在于B）；省字（不是A，是B／不是A，B才是）；反序（是A，不是B）；跨句（不是A。而是B／表面上A。其实B）；换字（与其说A不如说B）；以为体（以为A，其实／原来／才发现B；回头才发现）；让转体（看似A实则B／大家都说A，可B／恰恰相反）；抬价体（A不重要，重要的是B／真正X的是B／从来不是A）；否定排比（没有X，没有Y，只有Z）。对白同查，人物嘴里的翻案句改成转述或改成人物自己的正面判断（fullcheck「翻案外衣」硬项，「不是A，是B」「是A，不是B」人工裁）。
    - **禁用"一方面……另一方面……"**
    - **禁用"无论……都……"**
    - **禁用"然而"、"因此"等生硬转折**
    - **禁用序数词堆砌**：严禁使用"第一……第二……第三……"、"首先……其次……最后……"来组织段落。
    - **禁用斩钉截铁的断言**：减少使用"必然"、"绝对"、"毫无疑问"、"显而易见"、"众所周知"等过于肯定的表达。**语气过于肯定是AI味的深层死穴**。
5.  **情感描写必须"物理化"（拒绝抽象形容词·三层递进）**：
    - **禁令**：严禁直接使用抽象的形容词堆砌情绪。
    - **三层递进体系**：

      | 层级              | 说明                                     | 执行策略                     |
      | ----------------- | ---------------------------------------- | ---------------------------- |
      | **第一层·有反应** | 将情绪转化为生理反应、动作细节或环境投射 | 必须用具体细节代替抽象词     |
      | **第二层·留白**   | 不把所有情绪写在脸上，用镜头语言侧面烘托 | 像拍电影一样写小说           |
      | **第三层·失控**   | 身体先于大脑反应，镜头拉到毛细血管级     | 情绪上来时的"控制不住的反应" |

    - **核心原则**：有效细节不在于多而在于准。**一个能改变动作节奏的细节，比四个情绪形容词更有力量。**
    - **情绪落地顺序**：按序取一种——上下文已成立就不补；改变了下一步就写选择、台词、改价、撤回；场内物件出了什么变化；身体受影响且造成后果（签名写歪、钥匙插错）；低强度情绪一句直写更省时可以直写。身体细节过删除测试：删掉后信息、选择、关系、结果无损就删，不换部位、不换同义动作；§六-1「眼眶发酸」类须有后果才留。禁「一如他此刻的心境」式情绪翻译（fullcheck 硬项）。

6.  **环境描写的"人情味"与"主观视角"**：
    - 所有景物描写必须带有**人物当下的视角色彩**（情景交融）。
    - 尝试用人物独特的、个性化的感知来描写环境。
    - **环境限量与天气用途**：每场戏的纯环境句（不含人物动作、对白，只写天、光、声、陈设）连续≤2句，且须挂在人物动作或感知上；全章环境句不超过总句数的十分之一。天气只承担三种功能：时间锚；行动阻力（雨改了计划、风吹乱纸）；一次转场句。禁天气铺陈氛围、禁天气映射心情；「日子＋天气」式起场每章≤2（一键机检「天气起场」计数）。天气落笔前过机场逐时观测，查到钟点（R92）。
7.  **段落与句长（长短结合·拒绝机械节奏）**：
    - **拒绝"短句刷屏"**：避免连续出现 5 个以上的短句（10字以内），必须长短句结合。叙述默认口语化逗号长句（一句用逗号串起两到四件事再落句号），碎句电报体与 AI 腔同级处理。
    - **碎段合并与动作串**：短段只给揭示、冲击、停顿、切镜、钩子；连续3段以上的单句叙述短段（每段≤15字、非对白），除峰值外并回同一镜头。一句里超过三个动作，用「就、才、又、先……才」接出先后，不写成逗号清单。
    - **句内三连同构**：判断、抒情、总结性的三连同构句（同一引导词或同一句型连排三次）留两项，第三项换说法或删；动作链、物件枚举、专名并列不算。
    - **拒绝"排比段"**：连续 3 段不可使用相同的句式开头。
    - **句子长短要有变化**：在长句中间突然插入一个短句打断节奏，或者用一个动作、一句叙述把话截住（标点停顿三禁见§四-11④）。**句子的节奏要像说话，不像背稿。**
8.  **禁止上帝视角（视角锁定铁律）**：
    - 叙述严格限于当前视角人物**已知、已见、已经历**的信息。
    - **多视角切换规则**：需要展示非视角人物的独立场景时，必须用**空行 + 场景转换句**明确切换。
    - **深度沉浸（第一视角直播）**：全程恪守视角人物的**即时感官与情绪**——读者看到的不是剧情全景，而是跟着主角疼、跟着他慌、跟着他爽；不得跳出角色做客观描述或全景解说。
    - **信息生长禁令**：伏笔、钩子、情绪转折必须从视角人物**当下感知范围内生长**出来；禁止凭空生成超出主角认知的事件、物品、心理或背景信息来"做局"。
    - **8b 心理描写两档与代入感**：①**旁白式**（判断、盘算）用于推进情节、展示主角的脑子，写成他脑子里半句、带偏见、可被打断的判断，不写完整论证段；②**五感式**（感官先于判断：先写他听见、看见、身上觉出什么，判断后到或不到）用于压力峰值、情感节点、兑现前一拍，每章至少一处、每处≤3句、写完回到动作；五感不等于比喻，写实物、声音、温度、身体后果，比喻仍受§五-15 配额约束。③**理性主角补距离**：冷静、会算的主角天然有距离感，每章给他一处不完美（小失误、算错一笔、嘴硬一句、一个他自己没察觉的在意），落在动作上；技术或数字段之后紧跟一个人物反应或代价，不许连续两段纯技术／纯数字。控制卡逐章规格登记「五感点」。
    - **8c 重生者不降智（R101）**：写主角「不知道／没见过／做不来／没想过」之前，先查人物小传前世履历与本行身份；他知道却说不出（守口律）比他不知道更疼，优先写成前者；抬配角只抬配角的脾性与做法，不拿主角本行的基本功垫脚。
9.  **禁止破折号/冒号做解释旁白**：
    - 严禁用"——也就是说……""——这意味着……"等标点旁白向读者解释因果或设定。
10. **口语化自然感（保留"随意感"）**：
    - 叙述语言应带有日常说话的松弛和随意。
    - 书面词能换大众说法就换（"伫立"→"站着"，"凝视"→"盯着"，"旋即"→"马上"）。
    - **书面连接词替换对照表**：

      | 然而             | 但（或直接删）                 |
      | 此外             | 还有 / 再说了                  |
      | 总之             | 简单来说 / 反正                |
      | 至关重要         | 直接删，把要命的那件事写出来   |

    - **连接词替换执行策略**：每章写完后，必须grep高频连接词并逐一替换或删除。**宁可句子不完整，也不能用这些词把段落钉死在逻辑框架里。**

11. **全文文风一致性**：
    - 同一章内不得出现前半段文艺腔、后半段突然变口语的割裂。
    - 全书基调统一为"轻松口语+偶尔精准比喻"，章节间风格波动幅度不得超过±10%。
12. **禁止理中客观叙述腔（叙事立场铁律·AI味最深层死穴）**：
    - **死穴**：AI味最深层的特征不是句式套路，而是**"没立场、没情绪、没偏好"**。
    - **铁律**：叙述必须有**立场、有偏见、有护短感**。**宁可偏激，不可中立。**
13. **AI检测四维适配（检测逻辑前置）**：
    - 平台AI检测（朱雀等）识别机器稿的四个维度，逐维对应本书落点，动笔前即按此写作，不是写完再补救：

      | 检测维度          | 机器稿特征                         | 本书对策落点                             |
      | ----------------- | ---------------------------------- | ---------------------------------------- |
      | ①语言风格真实性   | 套话连篇、情绪为零、句式高度同质化 | §五-4禁句式＋§五-5情感物理化＋语气留余地 |
      | ②结构与逻辑复杂度 | 总分总八股、堆词不讲故事           | §四-6结构去八股＋每章"目标—阻碍—反转"    |
      | ③内容价值密度     | 放谁身上都成立的漂亮话             | §〇-2注水禁令＋每章必有具体细节增量      |
      | ④人设一致性       | 口吻漂移、人设模糊                 | §二人设一致性＋口头禅台账                |

    - **机味三标志（每章自查）**：套话连篇／情绪为零／句式高度同质化。三条中任何一条露头，该段重写。
    - **行业黑话黑名单（新增禁用词族）**：赋能、抓手、闭环、底层逻辑、颗粒度、链路、心智——凡叙述与对话中出现此类互联网/职场黑话，立即删改为大白话。**边界**：技术行话语境的"打法、链路（技术义）"等为正当行话，不在此列；人物职业语境（如陈序的程序员身份）允许技术词，但须按§三-2术语通俗化执行。**豁免**："逻辑链"为本书女主林见夏专属口头禅（≠"链路"≠"底层逻辑"），予以豁免；机检命中"链路"时人工分类，"逻辑链"不列入删改。
    - **洞察路标、名词化、抽象主语抒情**：禁「更X的是／还有一层／值得注意的是／需要指出的是／从某种意义上说／只说对了一半」与叙述句首「要命的是／要紧的是／关键是／问题是」抬价；禁名词化（进行了X、实现了X的提升、完成了对X的、起到了X作用、具有X意义）；禁抽象名词当主语配具体动词抒情（时间带走、岁月磨平、焦虑显形、时代甩下）；叙述层慎用机制、结构、层面、维度、进一步、深入、落实，对白按身份放行（fullcheck「洞察路标」「名词化」「抽象抒情」硬项）。
    - **人味三自检（每章交付前过）**：①读完全章，有没有"这人事儿真经历过"的具体细节？②有没有一句带着角色口头禅、让人点头或笑出声的话？③叙述里有没有一个不讨好但真实的判断（立场）？三条全空，即机器腔，返工。

14. **叙述的"非直线性"（思维指纹）**：
    - AI的思维是单向直线的；人的思维会跳跃、会自我质疑、会否定自己刚下的结论。
    - 内心戏与叙述中，允许并鼓励出现**自我修正**："他以为自己想通了——其实也不一定。""她说不在乎。说完自己先犹豫了。"
    - 人物对同一事件可以前后态度不一致，只要不一致有情绪依据。自我矛盾是活人的证据。
15. **AI高频脸谱化词库与描写配额（语言净化条款）**：
    - **比喻/具象描写配额**：整章比喻与具象描写合计**不得超过2处**；形容词整体极度克制。有效细节判据沿用§五-5——能改变动作节奏的细节才配存在。
    - **脸谱化词库（一律不得出现）**：松木香、瑞凤眼、修长的手指、指节、骨节、指腹、薄茧、一丝弧度、弧线……以此类推——凡"AI标准件"式人物外貌/气味/体态描写皆禁。
    - **眼神描写禁令**：禁止任何套路化眼神描写（"眸色一暗""眼底闪过什么"等），必须用动作、对话或具体生理反应替代。
    - **句式限制**：禁止用"那"作为叙述句的开头（按句首查，不只行首；对白里口语的"那个/那行/那边"等指示代词放行）；最大限度减少"动了"式微动作（"喉结动了动""手指动了动"一类）。
    - **绝对禁用修饰词库**：暂停键、钢针、指甲深陷入掌心、勾起一丝、深不见底、猪肝色、一丝、混杂、瞬间、死寂、沙哑、好整以暇、一抹等AI高频修饰词；并禁写一切对情节/情绪/人设无贡献的无用细节动作。
    - **万能副词与套式表情词库（叙述层零容忍，对白按人物口语放行）**：不禁、竟然、缓缓、微微、淡淡、似笑非笑、嘴角微扬／上扬／勾起、仿佛、犹如、宛若、宛如、如同、些许、隐约、深吸一口气、眼中闪过、眉头微皱、瞳孔微缩、心中一动、心头一震、心下了然、心中暗道、不由得、不由自主、情不自禁、话锋一转、映入眼帘、只见、此时此刻、说道／问道／笑道／沉声道、脸色一变、目光如炬、不容置疑、不易察觉、不可否认、前所未有、可谓、意义深远、未来可期、于是乎、与此同时、从而、因而、诚然、不难看出、事实上、取而代之、散发着、深邃、凛冽、狡黠、他感到／意识到／终于明白、这一刻。**句式同禁**：「，带着＋情绪／气息／语气」万能状语；「声音不大／不高，却……」；「语气平静得像在念／宣判……」；「听不出情绪」。同一禁用词一章多处命中，各处换不同的具体写法（fullcheck「②b 万能副词」「套式声线」硬项）。
    - **执行**：本章词库并入强制执行协议写作后步骤11b的grep机检，逐章零残留。

16. **深层AI指纹八禁（结构层·§五-4/7/8 的补充）**：

    **立条背景**：表层机检全绿≠没有AI味。实证：正文十章破折号/省略号/"不是…而是…"/禁用词机检**零报错**，编辑仍一眼判定"AI搞"。病灶全在结构层——**眼睛看不出来，必须过机检⑦**。本条同样适用于投稿大纲、简介等对外新撰文字（另见台账 R15／R17）。**本条各项所引「实证／改法」句只示范改法，禁止原句或近似句入稿**——示例搬进正文，读者只看得见补丁。**数字化验收（段长、标准差、配额）只作下限，不作目标**：写到刚过线就停，十章方差全压在同一窄带里，本身就是新指纹（lessons R35）。

    - **① 金句处置（按功能分类，不按数量）**：所谓「金句」须**先分类再处置**，混为一谈必然误伤。不按数量配额：人物台词与作者旁白不可同计，机械砍数先砍掉的是人物的命。
        - **A 类·动作之后的总结**（作者替读者把已经写出来的东西再说一遍）：**一律砍**。判据：砍掉后信息不丢、情绪不减，则此句本就是冗余。实证：ch7「到站没下，多坐了三站，等眼睛消了肿才往回走」之后原有「二十二岁，头一回知道，干活和功劳可以是两家人」，砍掉后留白更重；ch10「他在协议末页签字，手也没抖」之后原有「上回那个决定是别人替他做的。这回是他自己」，砍掉后动作直接落下，且它本身就是八禁的对偶模板。
        - **B 类·人物自己会说的话**（台词、口头禅、立场宣言）：**不限数量**，它们是人物的命。孙鹏「干活可以，留一手」、庞坚「轮不到新人教公司做事」，砍之即人物塌陷。唯一限制是**同一人同模板不得复用**（见人物小传·人物级限频）。
        - **C 类·叙述者跳出来点题**（旁白、时代评论、规则说明）：**砍，或落回人物当下的感知**。判据只有一问：这句是主角此刻能想到的，还是作者在跟读者讲话？实证：ch3「2011年的办公室，摸鱼摸得光明正大」已被前两句的《裸婚时代》与斗地主写尽，砍；ch4「轨道这东西，他碰过的地方，就会变」是插在白屏现场里的金手指说明，砍——**提前讲明金手指边界，会削弱后面记忆失效章的惊吓**。
        - **两条旧铁律不变**：**同模板严禁复用**（尤以"时间量＋只要/只需"式为甚，"十五年攒下的权限，回收只要三十秒"与"十五年，装箱只要四分钟"相邻并置即铁证）；**严禁段段收在金句上**，真人一章舍得给一个已算奢侈，AI 会段段都给。**删掉金句让读者自己得出结论，比替读者说出来更有力**（实证：删"时代把他甩下来了，时代甚至没空多看一眼"后，前一段的路人一瞥反而更狠）。
    - **② 段落长度必须失衡**：每章**至少 1 段 >120 字**（推荐 150–190，**硬上限 200 字**），段落字数**标准差 ≥25**。全章天花板整齐（无一段过 120 字）是模型生成的**物理指纹**——真人写到情绪上来必然失控出长段；长段落点选回忆/情绪高点/场面/独处收拾东西一类。**长段来源验收**：>120 字的长段须来自视角人物的个人回忆、情绪、独处感知或一个场面的连续动作；**禁止用「点名三五个人各做一件小事」的群像清单凑长段**。
      - **上限不可破**：超 200 字按镜头、新动作、新线索、视线切换断段，否则从"段段等长"掉进"一段到底"，是另一种模板腔（实测：第5、8章造长段时冲到 231/212 字，被 deslop `long-paragraph` 判中，拆段后过检）。**破天花板与控上限是同一条规则的两端，只做一端即矫枉过正。**
      - **提方差要靠极端值**：加一批接近均值的中等段落**反而会拉低**标准差（实测：第9章拆出4个短段，标准差从 23.1 降到 **21.5**；改为合并相邻段造长段后升到 **26.8**）。正解是压短爽点段、放长氛围段，两头拉开。
    - **③ 必须留废笔**：每章至少 1 处**无剧情功能**的闲笔——生活细节、无效思绪、跑题的观察（范例："杯子把手上有道裂，他一直想着哪天拿胶粘一下，想了五年也没粘"）。**"零废料"即 AI 指纹**：真人日更六千字不可能每段都有功能、每句路人台词都精准服务氛围。废笔不是注水，是质感；注水是重复已给过的信息，废笔是给新的无用细节，两者不可混为一谈。**废笔形态须轮换**：个人回忆、独处感知、跑题对话、记错的事、说了没下文的人……同一形态每章≤1，不得连续三章同形态；「想做X→没做成」式只许偶用。
    - **④ 禁事后全知旁白**：禁"后来他才知道""今天他才知道""多年以后""他不知道的是"等**跳出当下叙事时间**做点评的句子（§五-8 视角锁定在时间维度上的补充）。
    - **⑤ 禁对偶回环句**（并入§五-4 反AI句式禁令）：「有些X…有些X…」「是A，也是B」「X，或者不X」「如果是前者…如果是后者…」「梦里的人不会怀疑自己在做梦，会怀疑的，都不是梦」式回环，是 AI 中文最强指纹。**三种改法**：拆成白话；改成动作；或**删掉总述句直接上细节**（AI 爱"先总述再举例"，真人直接给具体——删"有些事他记得清清楚楚，有些事已经开始发虚"直接写"比特币他记得涨过几千倍…"，即此法）。

    - **⑥ 禁近距离重复措辞（同一动作/画面写两遍）**：同一措辞、同一动作、同一画面在 1200 字内重复出现，是生成冗余的**物理指纹**——落笔时模型不记得刚写过。实证：「把本子摊在桌上」隔一段写两遍；「搁在枕头边上」隔 56 字写两遍，且第二处"躺下之前"把时序写倒了；第 5、6 章「百叶窗留着条缝，人影举着电话走来走去」跨章一字不差复用。**刻意呼应可留**（题眼句复述、悬念锚点跨段提醒、远距离首尾呼应），理由须入控制卡；**相隔 <120 字的一律按冗余删改**。机检⑦ `near-repeat`。
    - **⑦ 禁群体反应模板与口癖节拍器**：「没人敢接话／没人答得上来／没人接茬」以及「静了几秒／静得反常／安静下来／鸦雀无声／谁也没说话」这类群体静默句，**一章至多 2 处**。实证：第 5、6 两章合计 6 处；六路重审时第 8 章一章 11 处，全是「静」字壳子。**改法是点名写一个具体的人的具体动作**（例："老周把捏扁的烟盒塞回兜里"胜过"没人答得上来"；"打印机卡纸的声音一下子很响"胜过"办公区静了一下"——示例只示范改法，勿原句入稿）。与④群像列举同源：**AI 写群体用概括，真人写群体只盯一个人**。**口癖节拍器同禁**：「看了他两秒／停了两秒」式计时停顿、「就三个字：……」式字数计数、「笑了笑（没接）」式万能反应，**每章各≤2**，计数类须数对（实证：十章计时停顿32处、字数计数27处且把四字的"怎么样了"写成"三个字"）。机检⑦ `crowd-template`／`tic-seconds`／`tic-charcount`／`tic-smile`；按功能计的全词表（含「没理／没答／没再说／半晌／像是／点头」等同功能变体）走机检⑧e `check_tics.py`。另两类：⑥**轻补语**（V了一下／一眼／一声／两下／一圈）叙述层≥5处且≥6处／千字即超；⑦**否定对偶**（没A，也没B／不A，也不B）叙述层每章≤2——削的时候换成有后果的动作或直接删，不换成另一种轻补语（R97）。
    - **⑧ 禁配角功能化台词（人人都说点题话）**：过场配角（摊主、房东、早点摊、保安、前台）每人一句精准点题的话，是**主题先行**的 AI 指纹——真人配角说废话、说跑题的话、说与主角无关的话。实证：烧烤摊主"以前我在厂里开机床，后来机床自己会开了"与主角处境严丝合缝地对仗，主角紧接着还内心复读一遍点题；房东王姐"年轻人，钱是挣不完的"与煎饼摊大姐"别熬坏了"同功能撞车。**三种改法**：总结改转述（"主任说，老哥你这手艺没的说，就是机器不累"）；说教改成具体的无关的人（"楼上那户小伙子也是你们这行的，上个月退租了"）；**删掉主角的内心复读——点题一次就够，第二次是冒犯读者**。

    - **机检⑦（每章必跑）**：`python ai-tasks/scripts/check_ai_taste.py 正文/卷一/第NN章.txt`
      **BLOCK 必改并重检**；WARN 人工过目，确有叙事功能方可留，理由须入控制卡。

每批控制卡至少含：`skill登记：NCS… / HW… / SLW…` 行；批次约束写明「已过签约红线自检」；小节 `## skill登记`、`## 批次约束`、`## 本批应完成`、`## 逐章规格`、`## 爽点循环`（五格＋「上一次当众兑现：第N章」＋超限理由）、`## 先演对照`（N+1 章兑现画面与刀子台词、三章内大纲锁定钩摆在手边，逐章写「本章不许先演什么」）、`## 线索热度`、`## 场次清单`、`## 时间链`、`## 法条与账`、`## 伏笔计划`；逐章规格表头含 章型／字数目标／日期／循环步／兑现（〔小〕〔众〕〔大〕）／五感点／废笔／长段材料；「前世回望本批≤2」计数行；交付前补「契约四问」「精读三处」结论。分工、矩阵、名单类事项先在卡上列口径表再写正文。`check_card.py 控制卡 --pre` 动笔前过，交付前不带 `--pre` 再过。可照 `ai-tasks/控制卡模板.md` 起卡。

## 〇·八、外部经验驳回登记（防回潮，后续不得再引入）

- 「短句为主」：本书叙述是口语化逗号长句，短句只作孤立重拍。
- 对白用破折号打断（「你—」）、钩子收在「——」：违停顿三禁，打断改动作或叙述截断。
- 「每章放一句能截图转发的金句」：数量配额与§五-16①冲突；人物台词（B 类）不限，作者金句（A／C 类）一律砍。
- 章节固定字数配比（承接200／升级800／爽点600／悬念400）：工整即指纹，只收「承接要快」（〇·一-4）。
- 底牌前兆写成系统提示、老爷爷咳嗽、物件发烫：违不能学清单与守口律，前兆只许主角视角内的记录、区间方向、验证、算账。
- 五章固定循环（人设1／铺垫2／打脸1／善后1）：与当众兑现≤3章冲突，本书按单元剧多轮小循环。
- 「后来他才知道」式闪前、「过了今天你们就笑不出来了」式预知钩：违事后全知旁白禁令与守口律。
- 「每章提及或使用金手指」：违守口律、折旧律；技术每章都在用，记忆不追加提及。
- 省略号「非零容忍」、「不要强行开篇对话」（番茄样本口径）：本书起点签约口径，省略号零容忍、冲突对话开场优先。
- 「对话标签密度≤30%」：本书文风是「对白后接某某说。」，只禁花式标签（说道／问道／笑道／X声道）。
- 「高潮兑现后不加危机」：违危机升级链；只收「收益先落袋、看得见」。
- 情绪映射环境的示范句（「玻璃桌面冰冷，一如她此刻的心境」「把手机扣在桌上」「心跳擂鼓」）：情绪翻译、撞全书限频画面、比喻超配额；只采五感方法，不采例句。
