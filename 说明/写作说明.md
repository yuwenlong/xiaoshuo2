### 失败处理流程

```
发现违规 → 立即停止 → 修正 → 重新验证 → 通过后方可继续
```

具体：

- 发现序数词 → 立即删除或替换 → grep验证 → 通过
- 发现斩钉截铁断言 → 立即改为留有余地 → 人工复核 → 通过
- 发现结尾拔高 → 立即改为动作/场景/疑问句 → 人工复核 → 通过

## 大纲节奏铁律（最高优先级）

以下规则具有绝对权威，任何情况下不可违背：

- **绝对依从**：后续续写必须严格按照《说明/全书大纲.md》的章节节奏推进剧情。
- **事件锁定**：严禁提前消耗、挪用或跳过任何大纲规划的核心事件（如告白、服战、见家长、求婚等）。
- **区间权威**：大纲的卷/章段划分是剧情节奏的唯一权威。某事件规定写在哪个区间，就必须落在哪个区间。
- **冲突处理**：若创作中出现与大纲冲突的新点子，**必须先请圣上定夺**是否修改大纲。获准后方可动笔；**严禁先写后改大纲迁就正文**。
- **控制卡核对**：每批章节动笔前，**控制卡**必须逐项对照大纲，核对本批应完成的剧情节点，确认无误后方可开始写作。
- **风格铁律**：全书执行"快节奏·强冲突"最高风格标准（见本文〇·一），每章必有可一句话概括的冲突核心+章末钩子六类轮换；与大纲节奏冲突时以本文〇·一为准。

## 〇、写作准则（最高优先级）

1.  **强制工具与提示词优化**：
    - **Skill 加载令（硬gate·每批动笔前必执行，缺一视为未过签）**：续写/审校必须使用 skills 能力进行小说创作，名单与必读文件锁定如下——
      1. **novel-control-station**：读 `SKILL.md`（控制体系，本书控制卡即其产物）；
      2. **human-writing**：读 `SKILL.md`＋`references/fiction.md`；初稿完成后再读 `references/revision.md`；
      3. **story-long-write**：读 `SKILL.md`，续写场景再读 `references/workflow-daily.md`；
      4. **story-deslop**（去AI味·交付前）与 **story-review**（审稿轮）按场景触发，触发即登记。
      **冲突仲裁**：skill 规则与本文冲突时以本文为准——human-writing「成稿正文严禁冒号、破折号」系散文禁令，不适用于本书对话与叙事标点；story-long-write 的 Phase 工作流、作者记忆脚本与本书「控制卡＋执行协议」体系重叠处，以本书体系为准。
      **登记**：每批控制卡必须含「skill登记」行，格式：`skill登记：NCS已读 / HW已读fiction.md / SLW已读`（本批触发 deslop/review 者一并登记）；无登记行视为未过签，机检⑥查之。
    - **关键**：必须**精心设计提示词**，而非简单的"写第XX章"。应明确告知AI本章的**核心任务、目标读者、需避免的词汇、特定的风格要求**。
    - **前置锚定（去AI化核心）**：提示词首句必须给AI塞入一个**带情绪、有立场的角色身份**，而非让它以"客观旁白机器"的身份写作。**平台AI检测的第一靶心就是"没偏好、没情绪、永远端着架子审视一切"的理中客文风**（详见§五-4）。
    - **锚定人设四件套**：给AI的角色身份必须同时携带——**身份**（具体的人，不是"资深专家"）＋**环境**（此刻在哪、刚经历了什么）＋**情绪**（带着什么心情写）＋**一处失败/不完美**（他搞砸过什么、正在为什么别扭）。专家人设必然产出"周到而正确"的论文腔；带失败经验的活人，笔下才有卡壳、有反问、有忽然冒出来的旁枝——这些"不顺"正是检测系统识别真人的指纹。

2.  **严禁注水（含"正确的废话"）**：
    - 不得为了凑字数而注水，确保内容高密度、高质量。
    - **判定标准**：通读全文后逐句问"删掉这句，读者会损失什么？"答案是"没损失"就果断删除。
    - **框架先行**：动笔前先搭好本章框架——列出要写的场景、要推进的信息点、要埋的伏笔。框架的作用是**事前发现空洞**。

3.  **核心原则（反AI死穴·人本注入）**：
    - **拒绝冷冰冰的概率文字**：文字必须带有"体温"和"痛感"，描写要有生理性的细节支撑。
    - **拒绝流水线套路**：即使是甜宠爽文，也要写出独属于两个主角的"黏稠感"和"烟火气"。
    - **拒绝直白宣泄**：学会"留白"，用环境、动作和微表情来映射情绪。
    - **注入个性化痕迹**：加入作者对生活细节的观察、独特的比喻、非线性的联想。
    - **语气留有余地**：AI的致命特征是**语气过于肯定**。人类写作天然带有犹豫、不确定和自我怀疑。**铁律**：叙述语气必须有松有紧，禁用"必然""绝对""毫无疑问""显而易见"等斩钉截铁的断言。
    - **不编造经验与事实**：涉及具体数据、机构、人名、年份的内容必须有来源依据；不确定的部分宁可不写。
    - **禁用序数词连接**：严禁使用"第一……第二……第三……"、"首先……其次……最后……"等序数词堆砌段落。改用情节推进、因果关系、时间流动来自然串联。
    - **删除结尾拔高式总结**：严禁用"综上所述"、"由此可见"、"我们要相信"等拔高式口号收尾。好的结尾是一个具体的动作、一个未完成的场景、一个悬而未决的疑问。

4.  **网络社区对话抗AI检测（核心命脉·本书无游戏世界观，对应物如下）**：
    - 博客评论区、公众号留言、QQ/雁信群聊、饭局群聊等纯对话场景是AI检测的"高危区"。**必须**在连续群聊对话中穿插私聊或主角内心OS，**每连续5行群聊对话内必须有打断**。
    - **必须**将群聊对话的通用词汇替换为该年代该圈子的专属黑话（以大纲「技术口径」年代栈与人物口头禅为准；年代网络梗宁缺毋滥，过期梗视同失真），增加专有名词密度以降低AIGC值。

## 〇·一、快节奏·强冲突总纲（投稿反馈修订·最高执行标准）

> 投稿反馈：主流网文平台签约门槛为**快节奏、强冲突、开篇爆炸**。本章为全书最高风格指令，与下文各章规范冲突时，以本章为准。

### 1. 开篇爆炸标准（黄金三章定生死）

- **第1章前300字**必须抛出核心冲突或强悬念事件，禁止任何形式的慢热铺垫、世界观介绍、背景叙述。
- **第1章**完成：主角辨识度场景 + 第一个冲突 + 章末强钩子。任务是把人钉在椅子上。
- **第2章**任务（让人坐住）：给出第一个小爽点/反转，回答"这人凭什么赢"；反派开始施压，但主角已亮出破局的苗头。
- **第3章**任务（逼他点下一章）：主角对阻碍给出解法，读者拿到一次小回报，同时埋下更大的雷。
- **前三章内**完成：核心关系钩子确立 + 第一个小高潮。
- **核心卖点亮相时限**：核心设定/身份钩子（金手指、书名承诺的前提）前三章内必须亮相；**亮相≠兑现**——身份要早亮，书名承诺的核心爽点仍按「〇·一-8 延迟兑现」压到节点引爆。
- **平台差异原则**：免费平台求快、付费平台求稳；本书执行最严档（第1章前300字抛冲突），不分平台降级。
- **前十章内**必须出现第一个"爽点"。
- **开篇字数标准层级**：①第一句话必须有钩子 → ②后续章节前100字必须出现动作/冲突/异常 → ③第1章前300字必须抛出核心冲突。
- **冲突对话开场优先**：首句优先落**冲突对话**——对话开场自带人声与立场，是3秒入戏的最短路径；正文前50字内宜直接抛出冲突对话（争吵、质问、爆炸性通知均可），交代背景一律后置。

### 2. 每章强冲突（全书通则·无冲突章禁令）

- 每一章都必须有一个**真正的冲突点/压力点**——对抗、阻碍、反转、抉择、外部事件、立场碰撞，至少其一。
- 每章**必须再有一个可一句话概括的冲突核心**。
- 即使是日常甜章，也要有"目标—阻碍—反转"的冲突结构，**阻碍必须真实存在并有压力**。
- **三问自检**：本章冲突能否一句话说清？冲突有没有明确的对抗方/阻力源？读者会不会替主角捏把汗或拍案？三问有一答否，即重写。

### 3. 信息密度三层论（反"伪节奏"·全书通则）

**信息三层递进**（由浅入深，每章至少覆盖两层）：

| 层级     | 说明                                             |
| -------- | ------------------------------------------------ |
| 事件信息 | 最表层——发生了什么、拿到了什么、去了哪           |
| 情感信息 | 藏在事件背后——读者心里觉得憋屈、释放还是感动     |
| 关系信息 | 最致命——角色间的信任/裂痕/试探发生了什么微妙变化 |

- **每写几千字必须塞一个读者没见过的"盲盒"**（意想不到的设定/反转/关系变化）。
- 如果一章只有事件信息（流水账式报幕），没有情感或关系层的推进，即"伪节奏"，重写。

### 4. 章末钩子强制（每章必落）

每章结尾必须落一个钩子，六类轮换使用，禁止连续三章用同一类：

| 类型     | 说明          | 示例（通用）                               |
| -------- | ------------- | ------------------------------------------ |
| 悬念未决 | 问题抛出未答  | "他发来一行字，她盯着看了十秒，没敢点开。" |
| 突发事件 | 新变量闯入    | 手机响了，来电显示是她最怕看到的名字。     |
| 情感转折 | 关系突然位移  | "以后别叫我老名字了。"                     |
| 秘密将揭 | 真相露出一角  | 备忘录里那一条，是空的。                   |
| 冲突升级 | 矛盾加码      | 公共频道刷出那句话时，全场静了。           |
| 反差收尾 | 预期违背/幽默 | 精心准备的现场，被最不该出现的人撞个正着。 |

- 钩子必须"具体、有画面、与下一章开头呼应"，禁止"他不知道的是……"式空泛预告连用。
- **钩子对话优先**：章末钩子优先用**一句具备悬念或反转力量的对话**承载（"悬念未决/情感转折/秘密将揭"三类天然适配对话式收尾）；仍受六类轮换、同画面不复用约束，不得为凑对话钩而连用。

### 5. 四件套：爽点·泪点·虐点·笑点（全书节奏骨架）

- **爽点**：每5-10章一个小爽点，每卷至少两个大爽点。
- **泪点**：每卷至少一个大泪点。
- **虐点**：每卷至少一个大虐点，虐后必须有回应（甜或爽）回收情绪。
- **笑点**：分散各章，虐章后一章宜有笑点缓冲。
- **配比红线**：连续甜≤5章必须插入一次张力；连续虐≤3章必须给出口；全书甜:虐≈7:3。

### 6. 节奏起落（全书情绪曲线）

- 每卷节奏为"起—扬—挫—爆"：卷首快速立冲突，卷中推进，卷末大高潮+大钩子。
- 卷与卷之间不许"软着陆"：本卷最后一章的钩子直接引爆下一卷开篇。
- 平台推荐节点（3万/8万/15万字前后）必须落在爽点或高潮章上。

### 7. 强冲突的执行边界

- 强冲突≠狗血：冲突须符合人设与逻辑。
- 冲突优先级：外部事件 > 立场对立 > 信息差误会。
- 甜宠/轻松底色不变：强冲突是"节奏引擎"，不是把甜文改成虐文。

### 8. 签约榜公式（扫榜对标·硬指标）

- **首句即炸**：执行「〇·一-10 开篇六条铁律」①②条。
- **反派速恨**：主要对抗方有名有姓、有自污细节，且当卷付出可视化代价。
- **人设动作化**：性格标签每章至多出现一次，此后只许用新的失误动作/行为细节呈现。
- **钩子去同质**：同类情感钩全书连用≤1次，画面不得复用。
- **延迟兑现**：书名、简介承诺的核心爽点用小道具/引信压到节点引爆。

### 9. 全书限频·连用规则表

| 约束项                                   | 额度              |
| ---------------------------------------- | ----------------- |
| 章末戏剧反讽（"她/他不知道……"式收束）    | 全书≤3            |
| 同类情感钩·同画面（如盯手机/扣手机心动） | 全书≤1·画面不复用 |
| "鼻子一酸/发酸"画面                      | 限频·去同质       |
| "耳朵热/红"心动画面                      | 全书≤4            |

> 上表各项的**已用数/落点章/备注**见该书大纲「写作红线·情节级」台账；每批续写收尾更新数据源。

### 10. 开篇六条铁律（3秒入戏·发布前必审）

| 条目        | 铁律                     | 执行标准                                                 |
| ----------- | ------------------------ | -------------------------------------------------------- |
| ①钩子扎进去 | 第一句话制造具体问题     | 钩子必须落在**具体事件**上，不是交代背景。               |
| ②麻烦追上来 | 三百字内三要素露面       | **主角是谁**、**眼前问题是什么**、**不处理会失去什么**。 |
| ③设定压人   | 设定必须影响人物选择     | 删掉这段人物选择会不会变化？不会就不该出现在这里。       |
| ④情绪往上拧 | 压力逐步升级             | 压力出现→人物选择→结果偏离预期→新问题被迫出现。          |
| ⑤让读者疼   | 用动作细节代替情绪形容词 | 一个能改变动作节奏的细节，比四个情绪形容词更有力量。     |
| ⑥关一扇门   | 章末钩子由本章结果逼出   | 好的章末钩子是**本章选择造成的后果**。                   |

**开篇写法对照**：

| 普通写法                                           | 更有效的写法                                                           |
| -------------------------------------------------- | ---------------------------------------------------------------------- |
| 大业七年，天下承平，西域诸国风云变幻。             | 城门落锁时，沈聿怀里多了一封不该出现的死人信。                         |
| 青崖山传承千年，门中分为七院，观微院专司……         | 沈聿没有拔剑。青崖山弟子不得在凡城先伤官兵——除非他愿意把使团也拖下水。 |
| 他呼吸急促，双眼通红，浑身颤抖，手指死死掐进掌心。 | 门外第三次响起脚步时，他才发现自己一直捏着那张纸。纸角已经被汗浸透。   |

### 11. 章内情绪流：三压一震（情绪曲线铁律）

- 每章情绪遵循**"前三番压、最后一震"**的递进结构：前三次冲突不断积蓄压力（一次比一次逼近主角底线），最后一次彻底引爆释放。
- 拒绝平铺直叙或一路萎靡的情绪曲线；甜章同样适用——压力可以是"想说不敢说""想信不敢信"这类内压。
- 自检：本章的三次加压点分别是什么？最后一震落在哪一段？答不出即重写。

### 12. 榜文沉淀·开篇与章内实操技法

> 以下为可复用技法，与上文各章规范配套执行；冲突时以本节上文条款为准。

**开篇下钩三法（任选其一，首段必须反常）**：

- **首句即反常**：第一句话抛出与日常逻辑相悖的画面或对话（牛顿在群里问作业、主角敲开仇家的门）。
- **他人之嘴**：主角未登场，先用旁观者闲话/群聊交代他的标签与死局；敌人之嘴与亲人之嘴各唱一台戏，一章内信息、冲突、感情伏笔三合一。
- **镜头急转**：先抛高信息密度的异质场景（告警刷屏、讨债现场），一句话拉回现实坐标（时间＋地点）。

**数字刺痛条款**：涉及钱、赔偿、房贷、投递次数、倒计时等现实压力，必须写具体数字（欠858.52元式精确到小数点），禁止"很多钱""欠了不少"式概括。

**每章一兑现一钩子**：章内必须兑现一个小回报（专业操作漂亮完成、被一句台词认可、关系位移），章末留一个更大的预期。压抑题材（裁员、意难平）压抑更深，必须加密小兑现密度补偿读者，否则弃书。

**配角一句立人**：配角首次出场只给"一个动作＋一句台词"，禁止背景介绍段；履历融在戏里交代。

**装孙子开局**：主角可先忍辱（赔笑、背锅、被晾），再凭真本事反转，爽感来自反差；反转必须有前文铺垫的凭据，禁止天降解围。

**对照组露馅法**：主角过难关（面试/述职/评审）之前，先写一个同处境者出丑落败，主角的紧张与含金量才有实感。

**危机升级链**：每章解决一个旧危机，同时引爆一个更大的危机；冲突优先级仍按〇·一-7（外部事件＞立场对立＞信息差误会）。

**专业即爽点**：把真实的排障、评审、重构、救火过程写细写香（如美食文写拉面炫技），专业细节承担情节转折功能，不是科普负担；仍受§三-2术语通俗化约束，且技术准确性按 `ai-tasks/lessons.md` 铁律执行。

**感情线只埋不碰**：感情暗线在开篇阶段只给碎片信息（一个名字、一张名片、一个空文件夹），不给正脸、不展开、不点破。

**情绪落在当下**：事发当下的内心戏要凉、要硬（动作/账本式短句）；"大概是…吧"式复盘调侃只给有时间距离的章节，压力现场禁用。

**隐喻不点破**：书名/题眼/主题隐喻只写可感短句，删"这道理搁在……也说得通"式画重点句；寓意交读者自架，作者不代答。

**提示配重**：给主角的提示/线索若不能立刻兑现，压到压力峰值处再放（"最后一根稻草"位）；提示早放而长期无效，读者必质疑；提示不得替主角解题，答案仍须主角自己挣出。

**沉默者往事被引出**：话少/命令式人设的角色不得主动讲带教导意义的往事，须由对方顶嘴或追问逼出；对话内禁止括号式术语解释（破人设），通俗化用口语加重词与后果呈现（§三-2配套执行）。

**不能学清单（红线）**：系统面板/任务提示/属性数值即时反馈、异能实物化（红包/抽奖/实物具现）、强刺激暴力尺度——本书金手指恒定为「重生记忆＋技术＋判断力」，受「一-6 先知兑现纪律」三律约束（模糊/折旧/守口）。爽点只许来自"信息差当众兑现＋技术降维打脸＋资产数字跃迁"，且每笔兑现必须配代价与反对声（一-6），禁无成本摘桃、禁记忆增值。

### 13. 榜文实证增补条款（榜单范文拆解沉淀·硬执行）

> 依据：三江榜5本＋新人签约新书榜5本＋新人作者新书榜5本逐本拆解（结论台账见 `ai-tasks/lessons.md`）。以下条款与上文冲突时，以本节为最新增补。

- **死局必须落在主角本人头上**：开篇危机是主角自己的危机（债务/死线/背锅/裁到主角本人），能量化必量化（金额/倒计时/名额，沿用数字刺痛条款）。主角旁观别人的危机只可作引线，不得作主冲突——压迫感隔一层，榜单文无一例外。
- **核心竞争力前三章内当场管用一次**：主角的立身之本（技术/手艺/阅历）必须当众解决一个具体麻烦。"身怀绝技但一直没机会展示"拖过三章即判慢热。
- **爽点必须有观众（外放兑现铁律）**：每章的小兑现必须配见证者反应——对手吃瘪、权威点头、同事改观、客户当众验收，至少其一。禁止"深夜独自完成、无人知晓"式内敛兑现单独成立；内敛场景可保留，但章内或紧挨的下一章必须补一个外放的承认时刻。
- **对照组先贬后立**：主角过难关之前，先给同处境者一句轻慢/质疑/失败（成本一两行），反转才有实感；该轻慢者在兑现时刻必须给一个反应镜头，形成闭环。
- **男频开篇感情线实证**：15本中11本前三章零女主——前三章无女主不是缺陷，是常态；「感情线只埋不碰」条款维持不变。凡简介、开篇以情感对话/情感悬念打头阵者，视为女频化红线，直接重写（内投退稿实证：简介言情化致编辑误判定位）。
- **简介频道对板条款**：简介先卖主线最硬的画面，情感暗线只留末尾一句钩；简介承诺什么，前三章必须交付什么，定位错位视同重大事故。

### 14. 外部审稿沉淀条款（外部审稿沉淀·硬执行）

- **禁单章纯生活戏**：每章必须推进至少一条剧情线（新事件/新矛盾/新钩子）；生活质感揉进事件章，不独立成章。
- **同构场景间隔红线**：相同骨架的"出问题→解决"模式两次出现间隔≥5章，再现时必须换呈现动作。
- **主角被动接招上限**：连续被动接招≤10章；超限前必须落一次主角自己决定、超出分内的主动出击。
- **口癖场景去复读**：同一配角同一口癖场景≥3次即报警；此后每次出场必须带增量（新信息/新动作/一句能记住的台词），否则压缩戏份。
- **重要配角隐身检测**：压力源型配角不得整章蒸发；真不出场须留存在感拍（一句话/一个动作/他人提及），控制卡登记原因。
- **身份级认知检验**：台词里的"不知道/没听过"须过人物身份检验；写"不会操作"可以，写"不知道本行业基础概念"失真。
- **伏笔滞后释放条款**：预警句与引爆不得同章相邻——"刚说一句'别乱动'，同章结尾就出事"的因果贴脸，读者只会"哦，果然"。预警句须单独成立（当时读不出指向、读者快忘了），引爆改由后章突发承载，回收时让读者与主角同一拍反应过来前文的指向。
- **台词分量匹配条款**：情感高点的台词分量须与人物资历、关系进度匹配。刚闯祸的新人/受惠者禁江湖式重誓（"我跟你混""赴汤蹈火"式）——分量过大即失真（"这小子怎么这么会说话"）；以动作（捧物不撒手、抹脸跟上）或轻台词（"我会学的"级）收尾，情感靠画面承载，不靠台词强调。

## 一、硬性规定（不可违反）

1.  **真实名分层（唯一权威以《全书大纲》「名称使用分层表」为准）**：真实公司名/产品名**允许中性提及**（淘宝、微信、寒武纪、996等公开史实陈述）；**禁止**对真实主体的贬损映射（"xx公司垃圾"式指向性贬损）、**禁止**真实人名及其言行、**禁止**未公开内幕；承载负面剧情的机构一律虚构名；真实地名与校名仍禁（统一用京城/深城等虚构名）。
2.  **字数要求**：每章不少于2000字，建议控制在2000-3000字之间。特殊情况最多不超过3500字。
    - **统计口径（永久生效）**：字数一律按**作家助手显示口径**统计——**中文字符与中文标点逐字计，连续的数字/字母/半角标点串整串只算1字**，与起点作家助手显示值一致，所写所验即读者所见。历史「去空白字符数」口径登记作废，以控制卡回写值为准；机检估算与作家助手实测误差±2字，凡压线目标（如补字/卡2000）一律预留30字以上余量。
    - **批次口径**：续写**每五章一批写、每五章一批验**。
    - **自然波动铁律**：同一批次章节字数**禁止均匀分布**。**每个五章子批的字数极差必须≥500字**。
3.  **平台违规内容红线**：严禁恶意丑化公务人员形象、严重违背伦理与主流价值观、无底线制造和煽动性别对立等。
4.  **版权规范**：不得抄袭、融梗，世界观设定原创。
5.  **跨章数据一致性（硬性·全书铁律）**：
    - **数值口径统一**：首次亮出时即登记口径，后续章节一律沿用登记值。
    - **名单锁定**：评审/答辩/裁员/投资/被投等名单类剧情，阵容与顺序写进控制卡为强制项。
    - **跨章时间链**：含"第N天/第N次/隔了N天"类计数时，落笔前先列逐日日历反推。
    - **同一物件来源唯一**：第二次写到同一物件，先grep前章出处。
6.  **先知兑现纪律（重生文专属·不可违反）**：
    - **金手指三律**：①**模糊律**——主角记得趋势与量级，记不住精确日期与价格，正文兑现一律写区间；②**折旧律**——蝴蝶效应使记忆随剧情加速作废，**每卷至少落一次「记忆失效/记错」惊吓章**（落点见大纲各卷注记），2022年后只剩方向感；③**守口律**——主角永不向人完整解释信息来源（F5悬疑线），"逻辑链"是他的全部说辞，**笔记本内页全文永不展示、丢失/被偷看桥段禁写**。
    - **投资必有摩擦**：每笔投资必须配齐「等待期＋反对声＋代价」三件套中至少两件；禁买买买流水账，无冲突不成章。
    - **数字精确可核验**：投资账目精确到个位数并与大纲「资产台账」对账（每批收尾核对）；落笔前必过大纲「时代锚点表」，拿不准写区间不写点值；**禁写现实可操作的荐盘口吻**（防误导防杠）。
    - **金手指禁升级**：记忆只能折旧不能增值；"他突然发现还能预知更多"式桥段出现即重写。

## 四、章节结构规范

1.  **章节标题**：口语化短句，长度自然不强求。
2.  **开头**：执行「〇·一-1 开篇爆炸标准」。**单章开头前100字内必须出现动作、冲突或异常信息**，禁止以天气、闹钟、起床流程开头。
    - **禁梦境/醒来铺垫型开头**：严禁"做了个梦……醒来全归零"式假剧情铺垫，直接入事，不铺垫"为什么"。
    - **禁配角视角开篇**：严禁从路人、反派或动物视角切入开篇；主角必须在300字内登场并行动。
3.  **结尾（拒绝拔高式总结·强制留白）**：每章结尾必落一个钩子（六类轮换），禁止平淡处断章。
    - **严禁结尾拔高**：禁止用"我们要相信"、"未来是无限的"等口号式总结收尾。
    - **正确做法**：用一个具体的动作、场景或疑问句结束。**留出未说完的部分，让读者自己去想。**
4.  **节奏把控**：执行「〇·一-4 四件套配比」；每章必有「〇·一-2 张力单元」，禁止无事件章。
5.  **篇幅节点控制**：分卷结尾应设置在平台关键推荐验证节点前后（如3万字、8万字、15万字等）。
6.  **结构去"八股文"化**：
    - **拒绝固定的"总分总"模式**：章节结构应服务于情节自然流动。
    - **过于工整本身即AI特征**：人工写作天然带有不规则性，刻意保留这种"参差"是对抗AI检测的有效手段。
7.  **对话行格式（全书统一·每批交付前必验）**：
    - 群聊、评论区等网络社区对话行**行与行之间必须有空行分隔**。
    - 叙述段落与对话行之间也须有空行分隔。
    - **交付校验**：每批章交付前须格式校验。
8.  **跨卷续写规范**：
    - **文件存放**：跨卷首章必须存入新卷目录。
    - **叙事衔接**：上卷末章的钩子必须在下卷首章承接。
    - **人物小传/线索表同步更新（强制·每批章完成后必做）**：新出场人物补小传条目；已有小传人物补新事件/台词/情感节点。
9.  **多章事件链跨章一致性（现实职场版）**：
    - **行情时间计量**：行情/股价/币价场景的时间词按交易日与月份计，与大纲「时代锚点表」对齐，禁用无出处的精确时点。
    - **数据驱动叙事**：资产/估值/用户量等数据口径须与大纲「资产台账」/控制卡一致。
    - **跨章事件链先画全链再动笔**：多章共用的大事件（裁撤日、股灾清仓、打新、IPO），动笔前先排出完整日期链与章位链。
    - **名单写进控制卡为强制项**（同一-5）。
10. **伏笔闭环机制（每章强制注明）**：
    - 每章交付时，在**控制卡**（或章末工作区，**不随正文发布**）附【伏笔处理】：
      - **回收**：收回前章伏笔「具体内容」，收回方式「写明如何触发、揭示」；
      - **新埋**：本章新埋伏笔「具体内容」，埋设位置「章节/段落」，关键细节「写明线索或异常点」。
    - 伏笔必须落在视角人物可感知的细节异常上（§五-8信息生长禁令），禁止凭空做局；台账同步记入该书大纲伏笔数据源。

11. **标点规范（全书统一·每批交付前机检零残留）**：
    - **引号**：对话、引语、强调一律用全角弯引号“”，正文严禁出现 ASCII 直引号 `"`；英文/代码片段作引语内容时外层仍用弯引号（如“jine”）。
    - **句中叙述语**：同一人的话被叙述语截断续说（“……，”某说，“……”），截断处用逗号不用句号；问号叹号保留；叙述语收句号另起新句时引号内句号不动。引语作句子成分（回了个“好”。）标点在引号外，属正确，不得误改。
    - **机检**：①grep 直引号 `"` 零残留；②grep `。”[^。”]{1,25}?，“` 零残留；③弯引号开闭计数相等。

## 五、文风规范（反AI死穴·情感物理化专项）

1.  **整体基调**：快节奏、强冲突，爽点泪点虐点笑点四件套齐备。**核心在于"真实感"与"个性化质感"**。
2.  **叙述视角**：第三人称，多主角视角均可。
3.  **对话比例**：对话段落占全文 40%-50%（**常规章档**，独处章与双人静场章另有区间，见下「章型区间」；**口径：按段落数计**——含对话的段落÷全文总段落数；引号内纯字符占比不作验收依据，仅供风格参考），**严禁**出现大段无对话的纯叙述或纯内心独白。**叙事加厚条款**：对话占比**上限50%**，对话之间必须以2-4句叙事段加厚感官/环境/动作细节。
    - **对话承载剧情**：核心剧情以对话推进，叙述只做加厚与转场，不抢戏。
    - **网感幽默条款**：笑点以对话承载，可自然植入网络流行梗制造笑点；**禁止用旁白或叙述硬挠笑点**。梗须贴人设、贴语境、不过期，一章至多1-2处，堆烂梗视同注水。
    - **口径注**：网传"对话占比70%+"**不适用于本书**——本书执行40%-50%＋叙事加厚，防纯对话流水账，与§三-5世界观占比红线配套。历史实测（引号内字符口径9%-40%）系口径混用，一律按段落占比验收。
    - **章型区间**：一刀切的40%-50%对两类章型夹得过紧（实证：ch148=39%／ch149=32%破下限、ch150=52%超上限，均系章型所致而非执行不到位），故按章型分三档验收——

      | 章型 | 判据（落卡时定，交付时按卡验） | 区间 |
      | ---- | ------------------------------ | ---- |
      | **独处章** | 全章无固定对手戏，主角独自行动（改简历/写博客/收拾东西/独自算账），对话只来自电话、IM、留言等远程介质 | **下限25%**，上限不设（超50%即非独处章，改按常规档） |
      | **双人静场章** | 全章基本只有两个人，且一方是限字人设（如周屿单句≤10字）或场景本身是静场（钓鱼/谈话/守夜） | **上限60%**，下限40% |
      | **常规章** | 上述两类以外全部 | **40%-50%** |

    - **章型判据铁律**：章型**必须在控制卡逐章规格里预先登记**，禁止交付时按实测值反推章型来迁就数字（那是"让规则去将就稿子"，与"让稿子去将就没校准的数"同罪）。一章只能挂一档；两档都像的按常规档。
    - **三档共同底线（不因章型放松）**：①对话之间仍须2-4句叙事加厚；②仍禁纯对话流水账与大段纯独白；③连续对话段无叙事打断、同一说话人连说两段无标识，仍为实质违规，与占比数字无关（lessons）。
4.  **反AI句式禁令（核心风控）**：
    - **禁用"不是……而是……"**
    - **禁用"一方面……另一方面……"**
    - **禁用"无论……都……"**
    - **禁用"然而"、"因此"等生硬转折**
    - **禁用序数词堆砌**：严禁使用"第一……第二……第三……"、"首先……其次……最后……"来组织段落。
    - **禁用斩钉截铁的断言**：减少使用"必然"、"绝对"、"毫无疑问"、"显而易见"、"众所周知"等过于肯定的表达。**语气过于肯定是AI味的深层死穴**。
5.  **情感描写必须"物理化"（拒绝抽象形容词·三层递进）**：
    - **禁令**：严禁直接使用抽象的形容词堆砌情绪。
    - **三层递进体系**：

      | 层级              | 说明                                     | 执行策略                     |
      | ----------------- | ---------------------------------------- | ---------------------------- |
      | **第一层·有反应** | 将情绪转化为生理反应、动作细节或环境投射 | 必须用具体细节代替抽象词     |
      | **第二层·留白**   | 不把所有情绪写在脸上，用镜头语言侧面烘托 | 像拍电影一样写小说           |
      | **第三层·失控**   | 身体先于大脑反应，镜头拉到毛细血管级     | 情绪上来时的"控制不住的反应" |

    - **核心原则**：有效细节不在于多而在于准。**一个能改变动作节奏的细节，比四个情绪形容词更有力量。**

6.  **环境描写的"人情味"与"主观视角"**：
    - 所有景物描写必须带有**人物当下的视角色彩**（情景交融）。
    - 尝试用人物独特的、个性化的感知来描写环境。
7.  **段落与句长（长短结合·拒绝机械节奏）**：
    - **拒绝"短句刷屏"**：避免连续出现 5 个以上的短句（10字以内），必须长短句结合。
    - **拒绝"排比段"**：连续 3 段不可使用相同的句式开头。
    - **句子长短要有变化**：在长句中间突然插入一个短句打断节奏，或者用省略号、破折号制造停顿。**句子的节奏要像说话，不像背稿。**
8.  **禁止上帝视角（视角锁定铁律）**：
    - 叙述严格限于当前视角人物**已知、已见、已经历**的信息。
    - **多视角切换规则**：需要展示非视角人物的独立场景时，必须用**空行 + 场景转换句**明确切换。
    - **深度沉浸（第一视角直播）**：全程恪守视角人物的**即时感官与情绪**——读者看到的不是剧情全景，而是跟着主角疼、跟着他慌、跟着他爽；不得跳出角色做客观描述或全景解说。
    - **信息生长禁令**：伏笔、钩子、情绪转折必须从视角人物**当下感知范围内生长**出来；禁止凭空生成超出主角认知的事件、物品、心理或背景信息来"做局"。
9.  **禁止破折号/冒号做解释旁白**：
    - 严禁用"——也就是说……""——这意味着……"等标点旁白向读者解释因果或设定。
10. **口语化自然感（保留"随意感"）**：
    - 叙述语言应带有日常说话的松弛和随意。
    - 书面词能换大众说法就换（"伫立"→"站着"，"凝视"→"盯着"，"旋即"→"马上"）。
    - **书面连接词替换对照表**：

      | AI惯用书面连接词 | 替换为口语化表达               |
      | ---------------- | ------------------------------ |
      | 然而             | 不过话说回来 / 但              |
      | 此外             | 还有 / 再说了                  |
      | 总之             | 简单来说 / 反正                |
      | 至关重要         | 要命的是 / 最关键的            |
      | 一个重要的问题是 | 但这里有个坑是                 |
      | 因此             | 所以（或直接省略，用动作衔接） |
      | 综上所述         | 直接删，不替                   |
      | 由此可见         | 直接删，用情节推进代替         |
      | 首先……其次……最后 | 直接删，用情节时间线串联       |
      | 第一……第二……第三 | 直接删，用因果/时间关系串联    |
      | 一方面……另一方面 | 直接删，用转折句或场景切换     |

    - **连接词替换执行策略**：每章写完后，必须grep高频连接词并逐一替换或删除。**宁可句子不完整，也不能用这些词把段落钉死在逻辑框架里。**

11. **全文文风一致性**：
    - 同一章内不得出现前半段文艺腔、后半段突然变口语的割裂。
    - 全书基调统一为"轻松口语+偶尔精准比喻"，章节间风格波动幅度不得超过±10%。
12. **禁止理中客观叙述腔（叙事立场铁律·AI味最深层死穴）**：
    - **死穴**：AI味最深层的特征不是句式套路，而是**"没立场、没情绪、没偏好"**。
    - **铁律**：叙述必须有**立场、有偏见、有护短感**。**宁可偏激，不可中立。**
13. **AI检测四维适配（检测逻辑前置）**：
    - 平台AI检测（朱雀等）识别机器稿的四个维度，逐维对应本书落点，动笔前即按此写作，不是写完再补救：

      | 检测维度          | 机器稿特征                         | 本书对策落点                             |
      | ----------------- | ---------------------------------- | ---------------------------------------- |
      | ①语言风格真实性   | 套话连篇、情绪为零、句式高度同质化 | §五-4禁句式＋§五-5情感物理化＋语气留余地 |
      | ②结构与逻辑复杂度 | 总分总八股、堆词不讲故事           | §四-6结构去八股＋每章"目标—阻碍—反转"    |
      | ③内容价值密度     | 放谁身上都成立的漂亮话             | §〇-2注水禁令＋每章必有具体细节增量      |
      | ④人设一致性       | 口吻漂移、人设模糊                 | §二人设一致性＋口头禅台账                |

14. **叙述的"非直线性"（思维指纹）**：
    - AI的思维是单向直线的；人的思维会跳跃、会自我质疑、会否定自己刚下的结论。

## 六、附加规范

1.  **活人感四瑕疵（高阶技巧）**：
